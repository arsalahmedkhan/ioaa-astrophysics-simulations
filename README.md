# 🔭 IOAA Astrophysics Simulations

Welcome! This repository hosts a collection of interactive dashboards and web-based simulators designed to help students train for the International Olympiad on Astronomy and Astrophysics (IOAA). 

All simulators load instantly, full-screen, and require zero setup or software installations.

---

## 🪐 Module 1: Celestial Mechanics & Mathematics

### 📐 Dot & Cross Product Interactive Lab
Visualize how position vectors ($\vec{r}$) and velocity vectors ($\vec{v}$) interact dynamically across an elliptical trajectory. Use this sandbox to evaluate dot products ($\vec{r} \cdot \vec{v}$) and cross products ($\vec{r} \times \vec{v}$) at different orbital phases.

👉 [**Launch Interactive Vector Simulator (Full Screen)**](https://YOUR_GITHUB_USERNAME.github.io/ioaa-astrophysics-simulations/dot-cross-product-interactive.html)

## 💡 Student Quick Start Guide
1. Click the **Launch Interactive Vector Simulator** link above.
2. The simulation will boot instantly in an edge-to-edge browser layout.
3. Adjust the **Semi-Major Axis ($a$)** and **Eccentricity ($e$)** sliders in the sidebar panel to see how the kinematics and telemetry vectors react in real time.
