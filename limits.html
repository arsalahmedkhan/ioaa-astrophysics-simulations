What is a limit?

Take f(x) = (x² − 1) / (x − 1). At x = 1 it is 0/0, so f(1) does not exist. The graph has a hole.

Yet near 1 the function is perfectly calm. Step in from both sides, a distance h away, and the outputs close in on 2. Zoom in as far as you like: the hole never fills, but the curve always points at it.

limx → 1 f(x) = 2Read: “as x approaches 1, f(x) approaches 2.” The value at 1 itself plays no part.

0.1

The idea

A limit asks where f(x) is heading as x gets close to a, never what happens exactly at a. That is why it works even when f(a) is undefined, or defined to be something else.

Try it

Press “Define f(1) = 3”. Does the limit change?

No. The limit only looks at x near 1, never at x = 1, so it is still 2. (This function is not continuous at 1: continuity means the limit equals the value.)

Turn on “Zoom in with h” and press Approach. Does the hole ever close?

No. At every scale the curve still has a hole at (1, 2). The limit is about the approach, not about filling the hole.

2

Why we need them

How steep is f(x) = x² at a single point P? A slope needs two points. So take a second point Q a distance h along, and measure the secant slope.

slope = [f(a + h) − f(a)] / h = 2a + hSetting h = 0 gives 0/0, which means nothing. Instead let h shrink toward 0: the slope approaches 2a. That limit is the derivative.

Every “instant” in physics hides this limit: speed at a moment, the rate a star dims during a transit. So does the small-angle rule sin θ ≈ θ behind parallax and angular size, which works because sin θ / θ → 1.

1

The idea

Calculus is built on 0/0 situations that only make sense as limits. The derivative f ′(a) = limh→0 [f(a+h) − f(a)]/h is the slope the secants settle on. Zoom in on any smooth curve and it straightens into its tangent.

Try it

Set a = 2 and shrink h. What slope do the secants approach?

2a = 4. The secant slope is exactly 4 + h, which tends to 4.

Switch to h < 0. Is the limit the same from the left?

Yes. 2a + h → 2a whichever side h comes from. For a curve with a corner, like |x| at 0, the two sides would disagree and there would be no derivative.

3

When limits fail

Approach a = 0 from the left and from the right separately. These give the one-sided limits.

limx→0⁻ f(x) and limx→0⁺ f(x)The limit exists exactly when both one-sided limits exist and are equal.

Pick a function. Some behave, and some fail in one of three classic ways: the sides disagree (a jump), the values blow up, or they never settle.

0.4

The idea

“Approaching L” has to hold from every direction and has to settle on one finite number. A jump fails the first test. A blow-up gives no finite number. Endless wiggling, as in sin(1/x), never settles at all.

Try it

For the Jump, what are the two one-sided limits?

0.5 from the left and 1.3 from the right. Both exist, but they differ, so the two-sided limit does not.

Both sides of 1/x² go the same way. Why is there still no limit?

They both grow without bound. ∞ is not a real number, so there is no finite limit. We write lim = ∞ only as shorthand for “grows without bound”.

4

Making it exact: ε–δ

“Close” is vague. Cauchy and Weierstrass made it a challenge game. Your opponent names a tolerance ε, the yellow band around L. You must answer with a δ, the teal strip around a, so that the graph inside the strip stays inside the band. The point x = a itself is left out.

For every ε > 0 there is a δ > 0 such that
0 < |x − a| < δ ⟹ |f(x) − L| < ε.If you can always win, however small ε is, then the limit is L. One ε you cannot beat is enough to prove L is not the limit.

The idea

The definition never mentions “getting closer over time” or infinitely small numbers. It is a promise: for any required accuracy ε there is some allowed wiggle room δ. A proof is a recipe that produces δ from ε, like δ = min(1, ε/5).

Try it

For x² at a = 2 with ε = 0.5, find a δ by hand, then check it with the slider.

The proof’s recipe gives δ = min(1, 0.5/5) = 0.1, which works. The largest δ that works is √4.5 − 2 ≈ 0.121.

Set L to 4.3 for x², then shrink ε. When does the game become impossible?

As soon as ε ≤ 0.3. Near x = 2 the values crowd around 4, which is 0.3 below the claimed L, so no δ can work. One unbeatable ε proves 4.3 is not the limit.

For the Jump, which ε can never be beaten?

Any ε ≤ 0.75, half the gap of 1.5. Whatever L you pick, one side of the jump stays at least 0.75 away from it.

5

Sequences: ε–N

A sequence a1, a2, a3, … has a limit L when its terms eventually stay inside any band you choose. Now you answer ε with a starting index N instead of a δ.

For every ε > 0 there is an N such that
n ≥ N ⟹ |an − L| < ε.The same game with x → ∞ gives limits at infinity for functions.

The idea

Early terms can do anything. Only the tail matters. Shrinking ε pushes N further out, but for a convergent sequence there is always a point after which every term behaves.

Try it

For 1/n with ε = 0.01, predict N before you check.

N = 101. You need 1/n < 0.01, so n > 100. The term a100 = 0.01 is not strictly inside the band.

Why does (−1)ⁿ have no limit, whatever L you try?

Its terms are 2 apart forever. For ε ≤ 1 they cannot all lie within ε of a single L, so no N works.

Summary

The intuition

limx→a f(x) = Lf(x) can be made as close to L as we like by taking x close enough to a, but not equal to a.

ε–δ definition

∀ε > 0 ∃δ > 0 :
0 < |x − a| < δ ⟹ |f(x) − L| < εAny tolerance ε can be met by some closeness δ.

One-sided limits

limx→a f = L ⟺ limx→a⁻ f = limx→a⁺ f = LBoth sides must exist and agree.

ε–N for sequences

∀ε > 0 ∃N : n ≥ N ⟹ |aₙ − L| < εEventually every term stays within ε of L.

Limit laws

lim(f ± g) = lim f ± lim glim(f g) = lim f · lim glim(f / g) = lim f / lim gThe last one only when lim g ≠ 0. Otherwise you get 0/0 and need more work.

Famous limits

sin x / x → 1  (x → 0)(1 − cos x) / x² → ½(1 + 1/n)ⁿ → eThe first is the small-angle approximation used for parallax and angular sizes.

Continuity

limx→a f(x) = f(a)f is continuous at a when the limit exists and equals the value there. No holes, jumps or blow-ups.

Derivative

f ′(a) = limh→0 [f(a + h) − f(a)] / hThe slope the secants settle on: speed, rates, gradients.

Common traps

The limit can exist where f(a) does not. A value at a can differ from the limit. “Plugging in” only works when f is continuous at a.
